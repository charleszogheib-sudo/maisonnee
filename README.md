# La Maisonnée

Appli familiale pour tablette : tâches avec points et récompenses, pénalités (code parent), liste de courses (envoi par e-mail), to-do de la famille, agenda Google de chacun avec rappels, contrôle du soir.

Ouvrir l'adresse GitHub Pages dans Chrome sur la tablette, puis menu ⋮ → « Installer l'appli ». Les données restent sur la tablette (sauvegarde dans Réglages).

`script-agenda.gs` : script Google Apps Script à installer une fois pour relier les agendas (voir Réglages → Rendez-vous et rappels).
